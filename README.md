# enzotoffanin-dev

Portfólio pessoal com projetos de desenvolvimento web.

## Projetos

Para adicionar um projeto, inclua um objeto em `src/data/projects.json`. Os projetos aparecem na ordem do arquivo. Use `"featured": false` se não quiser exibir um projeto na seção de destaque.

Para testar localmente, abra o site por um servidor HTTP. O navegador não carrega o JSON via `fetch` quando o `index.html` é aberto diretamente como `file://`.
